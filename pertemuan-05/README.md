# P4 - PROFIL MAHASISWA

## 1. Deskripsi Project

Project ini merupakan tugas Pertemuan 4 (P4) pada mata kuliah Pemrograman Web Dasar (PWD). Pada pertemuan ini, saya membuat sebuah halaman website sederhana dengan judul Profil Mahasiswa menggunakan HTML5 dan CSS.

Website ini dibuat untuk menampilkan informasi mengenai profil mahasiswa, mulai dari halaman beranda, tentang saya, hingga kontak. Selain itu, website ini juga dilengkapi dengan formulir yang dapat digunakan pengunjung untuk mengisi data diri dan menyampaikan pesan.

Dalam pembuatan website ini, saya mempelajari penggunaan struktur HTML5, elemen semantik, navigasi, serta berbagai jenis input pada formulir HTML.

## 3. Fitur Website

Website Profil Mahasiswa memiliki beberapa bagian utama, yaitu:

### A. Beranda (Home)
Bagian ini menampilkan ucapan selamat datang, perkenalan singkat mahasiswa, dan foto profil.

### B. Tentang Saya (About)
Bagian ini berisi informasi profil singkat mahasiswa serta target belajar yang ingin dicapai selama mempelajari Pemrograman Web Dasar.

### C. Kontak (Contact)
Bagian ini menampilkan tautan menuju profil GitHub dan formulir kontak yang dapat diisi oleh pengunjung.

### D. Formulir Kontak
Formulir dibuat menggunakan beberapa jenis elemen input HTML, yaitu:

- Nama lengkap menggunakan input text.
- Email menggunakan input email.
- Semester menggunakan input number.
- Tanggal kunjungan menggunakan input date.
- Jenis pesan menggunakan radio button.
- Topik yang diminati menggunakan checkbox.
- Program studi menggunakan select atau dropdown.
- Pesan menggunakan textarea.
- Tombol Kirim untuk mengirim formulir.
- Tombol Batal untuk mengosongkan formulir.

### E. Footer
Bagian footer menampilkan informasi hak cipta dan identitas mahasiswa.

## 4. Teknologi yang Digunakan

## 7. Cara Menjalankan Website

Langkah-langkah untuk menjalankan website Profil Mahasiswa:

1. Buka aplikasi Visual Studio Code.
2. Buka folder project Profil Mahasiswa.
3. Pastikan file index.html dan style.css sudah tersedia.
4. Pastikan foto profil berada di dalam folder img dengan nama foto-profil.jpg.
5. Buka file index.html.
6. Klik kanan pada file index.html.
7. Pilih Open with Live Server.
8. Website akan terbuka melalui browser.
9. Coba navigasi dan formulir yang tersedia untuk memastikan halaman dapat digunakan dengan baik.
