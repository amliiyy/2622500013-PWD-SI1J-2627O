# Profil Mahasiswa

## Deskripsi Project
Project ini merupakan tugas Pemrograman Web Dasar (PWD) yang dibuat menggunakan HTML5 dan CSS internal. Website ini menampilkan profil mahasiswa sederhana yang berisi informasi pribadi, target pembelajaran, serta formulir kontak.

Website ini dibuat sebagai latihan untuk memahami struktur HTML5, penggunaan elemen semantik, pembuatan formulir, dan penerapan CSS untuk mengatur tampilan halaman web.

## Fitur Website
Website Profil Mahasiswa memiliki beberapa bagian utama, yaitu:

1. **Beranda (Home)**  
   Menampilkan ucapan selamat datang, perkenalan singkat, dan foto profil mahasiswa.

2. **Tentang Saya (About)**  
   Berisi profil singkat mahasiswa dan target pembelajaran selama mempelajari Pemrograman Web Dasar.

3. **Kontak (Contact)**  
   Menampilkan tautan menuju profil GitHub dan formulir untuk mengisi data pengunjung.

4. **Formulir Kontak**  
   Formulir memiliki beberapa input, yaitu:
   - Nama lengkap
   - Email
   - Semester
   - Tanggal kunjungan
   - Jenis pesan (pertanyaan atau saran)
   - Topik yang diminati (HTML dan CSS)
   - Program studi
   - Pesan

5. **Footer**  
   Menampilkan informasi hak cipta dan identitas mahasiswa.

## Teknologi yang Digunakan
- **HTML5:** Digunakan untuk membuat struktur dan isi halaman website.
- **CSS:** Digunakan untuk mengatur warna, ukuran teks, jarak, garis tepi, dan tampilan formulir.

## Cara Menjalankan Website
1. Download atau clone repository project ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan file `index.html` dan folder `img` tersedia.
4. Pastikan gambar profil sudah dimasukkan ke folder `img` dengan nama `foto-profil.jpg`.
5. Buka file `index.html` menggunakan browser atau melalui ekstensi Live Server.
6. Website Profil Mahasiswa siap ditampilkan.
