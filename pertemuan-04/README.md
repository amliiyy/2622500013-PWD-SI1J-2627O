# Profil Mahasiswa

## Deskripsi Project
Project ini merupakan tugas Praktikum 4 mata kuliah **Pemrograman Web Dasar**. Website ini dibuat menggunakan HTML5 untuk menampilkan profil mahasiswa secara sederhana. Di dalam website terdapat beberapa bagian, yaitu Beranda, Tentang Saya, dan Kontak.

Website ini juga dilengkapi dengan formulir kontak yang berisi beberapa jenis input untuk mengumpulkan informasi dari pengunjung.

## Fitur Website

Website Profil Mahasiswa memiliki beberapa fitur, yaitu:

1. **Beranda**
   - Menampilkan ucapan selamat datang.
   - Menampilkan perkenalan singkat mahasiswa.
   - Menampilkan foto profil mahasiswa.

2. **Tentang Saya**
   - Menampilkan profil singkat mahasiswa.
   - Menampilkan target pembelajaran, seperti memahami struktur HTML5, menyusun halaman web semantik, dan memvalidasi dokumen HTML.

3. **Kontak**
   - Menampilkan tautan menuju GitHub.
   - Menyediakan formulir untuk mengisi nama lengkap dan email.
   - Menyediakan input semester dan tanggal kunjungan.
   - Menyediakan pilihan jenis pesan berupa pertanyaan atau saran.
   - Menyediakan pilihan topik yang diminati, yaitu HTML dan CSS.
   - Menyediakan pilihan program studi.
   - Menyediakan kolom untuk menulis pesan.
   - Memiliki tombol Kirim dan Batal.

## Teknologi yang Digunakan
- **HTML5:** Digunakan untuk membuat struktur dan isi halaman website.
- **CSS3:** Digunakan untuk mengatur tampilan website melalui file `style.css`.
- **Visual Studio Code:** Digunakan sebagai aplikasi untuk menulis dan mengedit kode program.
- **Live Server:** Digunakan untuk menjalankan website secara langsung di browser.

## Penjelasan File
- **index.html:** File utama yang berisi struktur halaman website, mulai dari Beranda, Tentang Saya, Kontak, formulir, hingga footer.
- **style.css:** File yang digunakan untuk mengatur desain dan tampilan halaman website.
- **README.md:** File yang berisi penjelasan mengenai project.
- **img/foto-profil.jpg:** Gambar yang digunakan sebagai foto profil mahasiswa.

## Cara Menjalankan Website
1. Buka folder project menggunakan Visual Studio Code.
2. Pastikan file `index.html`, `style.css`, dan folder `img` sudah tersedia.
3. Pastikan gambar `foto-profil.jpg` berada di dalam folder `img`.
4. Buka file `index.html`.
5. Klik kanan pada file tersebut, kemudian pilih **Open with Live Server**.
6. Website akan terbuka secara otomatis melalui browser.
